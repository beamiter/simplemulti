*simplemulti.txt*  Selection-first multiple editing for Vim9

:SimpleMultiNext             Select current/next word occurrence.
:SimpleMultiAll              Select every exact occurrence.
:SimpleMultiAbove            Add a cursor above.
:SimpleMultiBelow            Add a cursor below.
:SimpleMultiReplace [text]   Replace all selections.
:SimpleMultiInsert [text]    Insert before all selections/cursors.
:SimpleMultiAppend [text]    Append after all selections/cursors.
:SimpleMultiDelete           Delete all selections.
:SimpleMultiRemove           Remove the primary selection.
:SimpleMultiClear            Clear selections.

Vertical cursors retain their display column across tabs and short lines;
edits on a line shorter than that column are clamped to its end.

Default mappings are CTRL-N, CTRL-Up and CTRL-Down.  Set
g:simplemulti_default_mappings to zero before loading to disable them.

g:simplemulti_max_selections limits an all/next selection scan (default 1000).
It must be a positive number; invalid values fall back to the default.
